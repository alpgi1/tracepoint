### 1.3 Çalışma biçimi: "yap – doğrula – geriye bak"

Kullanıcının isteği (05 §2): "adım adım yavaş yavaş ilerleyelim, her adımda geriye dönüp kontrol et eksik bozuk bir şey var mı diye, kaliteli iş çıktığından emin olmalıyız".

`docs/04-faz6-uygulama-plani.md` §1: "Her adım şu üç parçadan oluşur: 1. **Yap** — adımın tek bir somut çıktısı var, yarım bırakılmaz. 2. **Doğrula** — adımın kendi doğrulama komutu çalışır ve geçer. 3. **Geriye bak** — aşağıdaki sabit kontrol listesi geçilir; kırılan varsa **bir sonraki adıma geçilmez.**"

**Sabit geriye bakış kontrolü (her adımda), birebir:**
- `pnpm typecheck` temiz
- `pnpm test` tamamı geçiyor (önceki adımların testleri dahil)
- `pnpm lint` temiz
- Python prototip testleri hâlâ geçiyor (`cd prototip && python3 -m unittest`)
- Bu adım bir spec'i veya K-kararını ihlal ediyor mu? Ediyorsa kullanıcıya sorulur
- Sabit sayı veya sabit renk gömüldü mü? (CLAUDE.md kural 3, yasaklı liste §6)
- UI adımıysa: `docs/tasarim/yasakli-liste.md` §8 teslim kontrolü
- Yeni bir varsayım ortaya çıktıysa V-kodu aldı mı?

**Adım kapanışı pratikte (05 §2), birebir:** 1. `pnpm format` sonra `pnpm check` (typecheck + lint + biçim + test). 2. Python prototip testleri. 3. Altın çıktı değişmedi mi: `python3 prototip/asama_ozet.py --yaz` sonra `git diff --quiet -- prototip/altin-cikti.json`. "Değiştiyse **hata**, onaylanacak çıktı değil." 4. `docs/tasarim/tokens.css` ve `.claude/` dokunulmamış mı (`git diff --quiet`). 5. Sabit renk / anahtar sızıntısı taraması (`git grep` izlenmeyen dosyayı görmez, yeni pakette `grep -rn`). 6. Yasaklı liste §8 teslim kontrol listesi — **ölçerek, gözle değil**. 7. `04` adım bölümü + ilerleme defteri + `05`. 8. Commit, push.

Kalite ilkeleri: "**Yeni koruma yazdığında bozarak dene.** Mutasyon testi geçmeyen koruma, koruma değil süs." (altın kilit, i18n korumaları, CSS mutasyonları, `hero.test.ts`, `bg-page-wash` kapsam testi hep kasten bozularak denendi). "Mutasyon betiğinin kendisi de yanılabilir" ("0 test düştü" şüpheyle karşılanır). "Düşmeyen mutasyon her zaman eksik test demek değil" (önce "bu davranış olmalı mı" sorulur). Kalite dayanakları: altın çıktı testi (TS motoru = Python prototipi, 49 senaryo), izlenebilirlik testleri (K21 matrisi), şema doğrulama (Zod), doküman–veri senkron testi, palet doğrulayıcı.
